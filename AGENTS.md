# Contexto para Agentes AI

## Stack

- **Frontend**: SolidStart (SolidJS) con TypeScript, renderizado SSR + CSR, rutas basadas en archivos
- **Backend**: API en Go (`api/`)
- **Auth**: JWT almacenado en `sessionStorage` (cliente) + HttpOnly cookie (server action)
- **Bucket**: MinIO/S3, URL centralizada vía `web/src/lib/bucket.ts`
- **Build**: Vinxi / Nitro, preset `deno-server-legacy`
- **CSS**: Tailwind

## Convenciones

- Nombres de archivos/rutas en minúsculas con guiones bajos (snake_case para español)
- Un solo commit por fix en la rama `docs`
- "no modifique el funcionamiento" — los cambios deben ser seguros y preservar el comportamiento existente

## Proyecto

Sitio web del Colegio de Psicólogos de Carabobo. Incluye:
- Páginas públicas (inicio, directorio, noticias, nosotros, explorar)
- Portal del psicólogo (`/psi/` — perfil, académico, modalidad de servicio, aviso de cumpleaños)
- Administración (`/admin/` — CRUD de psicólogos, noticias, áreas, staff, edad calculada, banner de cumpleaños, observaciones internas)
- Inscripciones (`/inscripcion` — ficha con validación de campos obligatorios que bloquea envío y edición admin)

(2) *"Las imágenes deberían estar en el dominio de envío"* — la bandera venía hotlinkeada de `upload.wikimedia.org` en 6 plantillas; ahora es `{{.SiteURL}}/bandera-carabobo.png` (PNG propio en `web/public/`, 330×220, 12 KB). **El SVG de Commons era un composed de 5 rasters embebidos, no arte vectorial, y Gmail/Outlook no renderizan SVG: era invisible en el correo aunque el aviso pasara.** (3) El contrato lo vigila `TestTemplates_SinRecursosDeTerceros`: recorre **todas** las plantillas embebidas, extrae cada URL absoluta del HTML renderizado y falla si el host no es el de `SiteURL`, y falla si algún `<img>` es `.svg` (comprobado en rojo reintroduciendo la URL de wikimedia). Ese test además cazó un defecto real que nadie había visto: `notification.html` escribía `{{.SiteURL}}.`, y al autolinkear el punto final se va con la URL dejando el host `…com.`; la URL va ahora en un `<a href>` con la puntuación fuera. Sin migración. ⚠️ Operativo: `web/public/` va **dentro** de la imagen (sin bind-mount), así que el PNG necesita `docker compose build web && docker compose up -d web` — contra el contenedor viejo el asset nuevo da 404 con el fallback SPA; y `docker compose build api && docker compose up -d api` para el binario. ⚠️ Los correos ya entregados no se reescriben: el fix evita el próximo envío con los avisos, no limpia la reputación ya acumulada (ver gotcha 23). |
