# AI Context: pkg/s3/

## Purpose: S3/MinIO file storage abstraction

## Key Functions
- `InitS3()` — Creates AWS S3 client from environment variables
- `UploadImage(file, folder)` — High-level upload with validation, returns URL
- `UploadImageToS3(file, folder)` — Internal multipart upload to S3

## Config
- `AWS_REGION` — AWS region (e.g., us-east-1)
- `AWS_ACCESS_KEY` — AWS access key ID
- `AWS_SECRET_KEY` — AWS secret access key
- `AWS_BUCKET` — S3 bucket name

## Limits: 10MB max file size

## Security
- UUID-based filenames prevent path traversal
- Content-type validation via http.DetectContentType
- Folder-scoped uploads
- Credentials from env only, never hardcoded

## Supports: AWS S3 and MinIO (local dev)

## Used By: internal/service/post_service.go, internal/service/psi_service.go
