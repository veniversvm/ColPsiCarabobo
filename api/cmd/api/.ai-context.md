# AI Context: cmd/api/
## Purpose: Main API server entry point and bootstrap
## File: main.go - Initializes all systems and starts Fiber server
## Boot Sequence: Config → DB → Seed → Migrate → S3 → Fiber → Middleware → Router → Listen

## Global Vars: db (database), S3 (storage), analyticsService
## Key Pattern: Database and S3 clients are passed as repository constructors, not global
## Graceful Shutdown: Listens for SIGINT/SIGTERM, 10s timeout for in-flight requests
