# AI Context: internal/config/
## Purpose: Singleton environment configuration (all env vars in one struct)
## Pattern: InitConfig() creates singleton, getEnv() reads with defaults
## Config Struct Categories:
  - Server: PORT(8080), ENVIRONMENT(development)
  - Database: HOST, PORT(5432), USER(postgres), PASSWORD, DBNAME(colpsi_db), DBDRIVER(postgres)
  - Storage: AWS_REGION(us-east-1), AWS_ACCESS_KEY, AWS_SECRET_KEY, AWS_BUCKET
  - Email: SMTP_HOST, SMTP_PORT(587), SMTP_USER, SMTP_PASS, SMTP_FROM
  - Environment: GOENV(development)
## Env Vars: 15+ environment variables with sensible defaults
## Usage: config.InitConfig() at boot, then config.Config{} everywhere
## No .env file: Uses OS environment variables (set via docker-compose or shell)
