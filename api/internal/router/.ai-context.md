# AI Context: internal/router/

## Purpose
Route definitions and middleware mounting for all API endpoints

## Files
- `router.go` — InitRouter, sub-routers orchestration
- `psi_router.go` — Psychologist routes
- `post_router.go` — Post/CMS routes
- `admin_router.go` — Admin management routes
- `specialty_router.go` — Specialty catalog routes

## Base Path
`/api/v1/`

## Route Groups
- `/api/v1/admin/auth/*` → AuthController (login, register) + RateLimiter
- `/api/v1/admin/*` → AdminController (CRUD) + AuthRequired
- `/api/v1/psi/*` → PsiController (profiles, directory) + AuthOptional
- `/api/v1/posts/*` → PostController (CMS) + AuthOptional
- `/api/v1/specialties/*` → SpecialtyController + AuthOptional
- `/api/v1/analytics/*` → AnalyticsController + AuthRequired

## Middleware Applied
Analytics (all), Auth (per-route), RateLimiter (auth endpoints)

## Total Endpoints
~22

## Pattern
Each module has its own router file, `InitRouter()` orchestrates all

## Uses
All handlers, middleware functions, config
