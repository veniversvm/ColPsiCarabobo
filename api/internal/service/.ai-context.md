# AI Context: internal/service/
## Purpose: All business logic — the "brain" of the application
## Services (10):
  - AdminService: Auth (JWT with key rotation), CRUD, permission matrix, cached listings
  - PsiService: Psychologist profiles, directory search, privacy shield, Excel import, solvency
  - PsiUserAdminService: Admin-level editing of psychologist records (no privacy restrictions)
  - PostService: CMS posts, ACL (author-only edit), S3 images, category filtering, slug lookup
  - SpecialtyService: Catalog management, soft delete, fail-safe defaults
  - AnalyticsService: Event recording (goroutines), dashboard stats, data purging
  - MailService: Async email (producer-consumer pattern), anti-spam throttling
  - ErrorMapper: DB error → Spanish message translation
  - SocialMedia: Social network CRUD, IDOR protection, 10-network limit
## Key Patterns:
  - JWT Key Rotation: Secret rotates, old tokens valid during grace period
  - Privacy Shield: Public profiles hide sensitive data (cedula, email, phone)
  - Saga Rollback: On failure, uploaded images are cleaned up from S3
  - Fire-and-Forget: Analytics events recorded in goroutines (no blocking)
  - Cached Listings: sync.Map for frequently accessed data
  - ACL: Role-based + ownership-based access control
## Security: Passwords bcrypt-encrypted, IDOR prevention, rate limiting integration
## Error Handling: Custom codes 1001-9001, Spanish messages, mapped from DB constraints
## Dependencies: domain interfaces, repository implementations, config, utils, s3, templates
