# AI Context: internal/middleware/
## Purpose: Security perimeter — auth, rate limiting, idempotency, analytics
## Files: auth.go, rate_limiter.go, idempotency.go, analytics.go, auth_test.go
## Middleware Chain Order: Analytics → RequestID → CORS → RateLimiter → Idempotency → Auth (per-route)
## Auth:
  - JWT validation from Authorization: Bearer <token>
  - Role extraction: ADMINISTRADOR, SUPER_USUARIO, USUARIO
  - Admin 404-Hiding: Non-admin users see 404 for /admin routes (not 403)
  - Hybrid Auth: Optional token support (public + authenticated behavior)
  - Psi Protection: Psychologist users restricted to own data
  - c.Locals(): userId, userRole, userEmail
## Rate Limiter:
  - Auth: 10 req/15min per IP
  - Admin: 5 req/30min per IP
  - Returns 429 with Retry-After header
## Idempotency:
  - SHA-256(body + userId + path) as key
  - Prevents duplicate mutations (POST/PUT/DELETE)
  - TTL-based expiration
## Analytics:
  - Session cookies (30min, UUID)
  - Fire-and-forget goroutines for DB writes
  - Tracks: page views, profile views, search events, login events
## Security Test: auth_test.go validates all auth scenarios
