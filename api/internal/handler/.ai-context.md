# AI Context: internal/handler/
## Purpose: HTTP request/response interface layer (Fiber v2 context)
## Architecture Role: Translates HTTP → Service calls → HTTP response. Thinnest possible layer — zero business logic.
## Files:
  - psi_handler.go: PsiHandler (15 endpoints — login/logout, public profile, directory, self-management, postgrades, social networks, CSV upload, sitemap)
  - psi_user_admin.go: PsiHandler methods (5 admin-only endpoints — full record access, create, update, delete, list-all)
  - posts_handler.go: PostHandler (5 endpoints — CRUD, list with role-based visibility, sitemap)
  - admin_handler.go: AdminHandler (5 endpoints — login, CRUD staff, hierarchy verification)
  - specialty_handler.go: SpecialtyHandler (7 endpoints — public catalog, CRUD, count, admin list-all)
  - analytics_handler.go: AnalyticsHandler (1 endpoint — dashboard stats)
## Pattern per handler: Parse request (c.BodyParser / c.QueryParser / c.Params) → Validate via request_structs → Call service method → Map response to JSON → Return HTTP status
## Dependency Injection: Each handler receives its service via constructor: New*(svc *service.*Service). Analytics handler also receives *service.AnalyticsService.
## Auth Integration: Handlers receive decoded JWT claims from middleware via c.Locals("admin") *domain.UserAdmin, c.Locals("psi_user") *domain.PsiUserModel, c.Locals("userID") uuid.UUID
## Privacy Shield: Public profile handler applies show_* flags to filter sensitive data. Admin handlers bypass all privacy filters.
## File Upload: Multipart form handling via c.FormFile() for images (profile pictures, title images, post covers, postgrade certificates). Files → S3, keys → database.
## Response Pattern: Success → 200/201 + { "data": [...], "total", "page" } or { "message": "..." }. Error → 4xx/5xx + { "error": "message in Spanish" }
## Analytics Integration: PsiHandler methods call analytics.Record*() AFTER successful operations (search, profile view, login, logout) for metrics tracking
## Role Detection: ListPosts/GetPost detect role ("public"|"psi"|"admin") from c.Locals to determine content visibility ACL
## Key Dependency: handler → service → domain (never imports infrastructure directly)
## Total Endpoints: ~33 across all controllers (11 public, 22 authenticated)
